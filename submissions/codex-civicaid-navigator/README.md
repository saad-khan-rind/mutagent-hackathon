# CivicAid Navigator

AI 4 Good Hackathon submission for the Mutagent side challenge.

CivicAid Navigator is a local-first resource triage agent for disaster recovery and urgent social-service intake. It classifies a resident's needs, checks safety and escalation risk, searches a vetted local resource catalog, ranks eligible resources, asks only the missing questions that matter, drafts a handoff-ready resident message, and writes an auditable decision trace.

## Run

```bash
npm test
npm run evaluate
node agent/cli.js eval/case-example.json
```

No provider keys are required. The agent and eval harness use deterministic local tools so the scorecard can be reproduced by judges.

## Mutagent Lifecycle Evidence

- `agentspec.yaml` is the `*spec` output.
- `adl/build-report.md` is the `*build` output.
- `eval/cases.json` contains 24 concrete eval cases.
- `eval/results/scorecard.json` and `eval/results/scorecard.md` are the final `*evaluate` outputs.
- `adl/diagnosis-report.md` and `adl/improvement-report.md` record the `*diagnose` and gated improve loop.
- `extensions/risk-drill/` adds the bonus `*risk-drill` lifecycle stage between build and evaluate.
- `transcripts/` contains the Helix and stage-session logs used for this submission.

## Agent Capabilities

- Jobs: intake triage, safety escalation, resource matching, eligibility filtering, resident-facing draft, provider handoff, audit trace.
- Tools: local resource catalog search, ZIP/city matcher, need classifier, safety escalator, ranker, response composer, outbox writer.
- Triggers: manual case review, webhook payload, scheduled recheck, queue batch processing.
- Integrations: local JSON resource catalog, CLI/stdin, JSONL outbox handoff, optional webhook-shaped payloads.
